This policy describes how pLabs Entertainment (“Funebra”, “we”, “the app”) handles data when you use the optional Google Photos import feature. The contact details currently supplied for the operator appear in section 10.

1. What the feature does

The feature lets you use Google Photos Picker to select exactly one photo for an import. Funebra uses that selected photo to create pixel-based BN (point) configurations in the Math-Art Engine. You can create more than one configuration from the imported image.

The feature does not list or import other library photos, create face clusters or perform facial recognition, train shared machine-learning models with imported photos, or operate a general-purpose photo gallery.

We do not request or store your Google account name or email through this feature. The selected image is downloaded by the Worker using Google’s temporary media URL, which is not sent to the static engine.

3. How we use the data

  • Download the one photo you chose and store it as a private source asset.
  • Return that stored image to your browser so the Math-Art Engine can sample pixels and create ImageBN configurations.
  • Record the asset metadata and provenance described above and provide a way to delete the stored asset.

The image-derived configurations are generated in the browser. They are not uploaded to the import service by this prototype. If you export a configuration, the downloaded file may contain the source asset ID and provenance, pixel coordinates and sampled colors; it does not contain the image bytes or delete-only key.

4. Storage and security

  • Image bytes are stored in a private Cloudflare R2 bucket; asset and short-lived session records are stored in Cloudflare Workers KV.
  • Cloudflare documents encryption at rest for R2 objects and Workers KV values. Data is transmitted over HTTPS.
  • The engine does not receive the Google bearer token or temporary Google media URL. It receives a separate short-lived Funebra session token and the selected image bytes.
  • Reading the stored image requires the active session that imported it. The delete-only key can authorize deletion after that session expires.

5. Providers and sharing

Google Photos provides the user selection and temporary download access. Cloudflare provides the Worker service, KV and R2 storage. The selected image is transmitted from Google to the Worker and stored in R2; it is also returned to your browser for BN generation. We do not sell imported photos or use them for advertising.

Before external launch, the operator will verify and describe applicable provider terms, data-processing roles, and storage locations. This prototype does not send imported images to other analytics, advertising, or machine-learning services.

6. Deletion and data rights

  • Delete the source asset: Use “Delete imported source image” in the engine panel and confirm. The Worker deletes the R2 object and its asset record.
  • Deleting the source asset does not remove BN configurations already downloaded or saved elsewhere. Delete those files separately if you no longer want them.
  • If you clear browser storage before deleting, contact the operator with the asset ID from your BN export so the asset can be located.
  • After the photo is downloaded and stored, the Worker requests deletion of the Google Picker session. If Google does not confirm deletion, the session remains subject to Google’s expiry. If an import is abandoned, Google’s session expires according to its expiry; the Worker’s local Picker-session mapping expires after 15 minutes.
  • You may contact the operator to request access to or deletion of data associated with your import. Applicable data-protection rights and complaint routes depend on the operator’s confirmed role and your jurisdiction.

7. Google Photos API use

Funebra requests only the https://www.googleapis.com/auth/photospicker.mediaitems.readonly scope. Photos API data is used only to provide the user-selected image-to-BN import. The feature does not create face clusters or a general-purpose photo gallery. The in-app disclosure appears before the Google authorization request. See Google’s Photos API User Data and Developer Policy.

8. Children

This prototype is not directed to children under 13 (or the applicable age in your jurisdiction). Do not import photos unless you have permission and authority to use them.
