Funebra Google Photos import — data notice

Prototype notice: Before enabling this integration for anyone beyond its operator, replace this notice with a complete privacy policy that identifies the responsible legal entity, contact details, retention terms, and applicable data rights. Google OAuth verification may also be required.

What you choose and what happens

When you select “Connect Google Photos,” Funebra requests the Google Photos Picker permission to create a selection session and receive the photo you choose. The integration is designed to import exactly one selected image at a time. It does not list or download the rest of your Google Photos library.

The selected image bytes are sent over HTTPS to Funebra’s import service, stored in a private Cloudflare R2 bucket, and used by the Math-Art Engine to create pixel-based BN configurations. The import service also records the filename, image dimensions, SHA-256 hash, import time, and Picker provenance identifiers. The engine’s BN configuration contains sampled pixel coordinates and colors.

Temporary Google access tokens are held by the import service only for the short-lived import session. The engine receives a separate short-lived session token. The image object remains in the private asset store until you delete it.

How to delete data

After importing, use “Delete imported source image” in the engine panel and confirm the deletion. A delete-only control key is kept locally in this browser so deletion remains available after the Google authorization session expires; it is not included in the exported BN configuration. Deletion removes the stored image bytes and asset record. A BN configuration already generated in the current browser remains available to export; delete that downloaded JSON file separately if you no longer want it. If you clear this browser’s local storage before deleting, contact the service operator with the asset ID from your BN export. An import that was interrupted before the asset was returned may leave a temporary Picker session until its short expiry.

Use limitations

Photos API data is used only to provide the user-selected image-to-BN import feature. The service is not a general-purpose photo gallery, does not build face clusters, and does not use imported photos to train or improve shared machine-learning models. Do not import photos you do not have permission to use.

Provider disclosure

Google Photos provides the selection and temporary download URL. Cloudflare provides the Worker and private R2 storage. Cloudflare documents AES-256 encryption at rest for R2 objects and Workers KV values. See the R2 data security documentation and Workers KV data security documentation.

The operator must publish accurate contact details and a complete privacy policy before inviting other users to connect an account.
